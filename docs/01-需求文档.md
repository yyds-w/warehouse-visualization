# 简简仓库可视化系统 — 需求文档

## 1. 产品是什么

简简仓库可视化系统是一款面向仓库管理的 **2B SaaS 工具**，通过在线可视化平面图、货架/货位管理与智能找货功能，帮助企业把仓库布局、库存状态、空间利用率以图形化方式直观呈现，从而提升仓储管理效率。

## 2. 解决什么问题

传统仓库管理存在以下痛点：

- **CAD 复杂、手绘繁琐**：传统平面图绘制依赖 CAD 或手工绘制，门槛高、效率低、更新慢。
- **找货循环低效**：拣货人员依赖记忆或纸质单据，找货时间长，容易出错。
- **库存状态不透明**：仓库空间利用率、各子仓库库存分布缺乏实时可视化看板，决策滞后。
- **信息孤岛**：仓库基本信息、库管信息、货架信息、货位信息分散，难以联动。

本产品通过"3 分钟在线绘图 + 智能识别 + 全景看板 + 秒级找货"的方式，让仓库管理从纸质/经验驱动转向可视化、数据驱动。

## 3. 有哪些界面

| 序号 | 界面名称 | 主要功能 |
|------|----------|----------|
| 1 | 仓库平面图绘制页 | 在线绘制仓库平面图，右侧属性面板实时调整尺寸；支持导入 CAD/手绘图智能识别。 |
| 2 | 仓库基础信息管理页 | 录入仓库基本信息、库管信息、子仓库信息，自动生成/关联可视化平面图。 |
| 3 | 货架配置页 | 像搭积木一样配置货架：单排/双排、行数、排数、层数、列数等参数化调整，实时预览，修改货架名称，导入货架信息。 |
| 4 | 全景可视化看板 | 一屏掌握所有子仓库，展示库存、空间使用率等核心数据；双击子仓库进入区域货架可视图。 |
| 5 | 区域货架视图 | 展示某一子仓库内的货架布局、货位状态、库存占比。 |
| 6 | 货位详情/智能找货页 | 多维度筛选、联动图表、库存占比与状态分布；鼠标悬停显示货位完整信息；支持按编号精准查找或按品名模糊搜索，秒级定位目标货位。 |

## 4. 界面之间如何交互

整体交互流程遵循"先建模、再看板、后找货"的主线：

```
仓库基础信息管理页
        │
        ▼
仓库平面图绘制页 ──（导入/识别）──▶ CAD/手绘图
        │
        ▼
货架配置页 ──（参数化生成）──▶ 货架数据
        │
        ▼
全景可视化看板
        │
        ├── 双击子仓库 ──▶ 区域货架视图
        │
        └── 全局筛选/搜索 ──▶ 货位详情/智能找货页
```

### 4.1 核心交互说明

- **仓库基础信息管理页 → 仓库平面图绘制页**  
  录入仓库名称、面积、库管人员、子仓库划分等基础信息后，系统可一键生成初始可视化平面图，也可进入绘制页进行手动细化。

- **仓库平面图绘制页 → 货架配置页**  
  平面图绘制完成后，用户在图上指定货架区域，进入货架配置页设置货架参数（单双排、行列层列等），系统自动生成货架与货位模型。

- **货架配置页 → 全景可视化看板**  
  货架配置数据同步更新至全景看板，空间利用率、库存总量等指标实时刷新。

- **全景可视化看板 ↔ 区域货架视图**  
  看板以子仓库为入口，双击某个子仓库卡片/区块后下钻到区域货架视图；区域视图提供返回看板的面包屑导航。

- **区域货架视图 → 货位详情/智能找货页**  
  在区域视图中点击具体货位，弹出/跳转货位详情；也可通过顶部搜索栏输入货位编号或商品品名，系统瞬间定位并高亮目标货位。

- **智能找货结果 → 区域货架视图/全景看板**  
  搜索结果支持反向定位：找到目标货位后，可一键跳转到对应子仓库的区域货架视图，并在图中高亮显示。

## 5. 关键验收指标

- 支持 3 分钟内完成仓库平面图在线绘制。
- 支持 CAD/手绘图智能识别，识别准确率满足日常管理需要。
- 空间利用率提升约 45%，拣货效率提升约 80%。
- 找货响应时间从分钟级压缩至秒级。
