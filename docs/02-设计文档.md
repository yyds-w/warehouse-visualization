# 简简仓库可视化系统 — 设计文档

## 1. 设计目标

- 支持仓库、子仓库、货架、货位、库存的多层级数据建模。
- 支持平面图与仓库结构的联动：修改平面图尺寸时，货架/货位坐标可自适应或提示冲突。
- 支持智能找货：通过货位编号、商品名称、商品编码等多维度快速定位。
- 保证核心表结构简洁，便于后续 CRUD 模块实现。

## 3. 表间关系（ER 概述）

```text
warehouse (1) ──────< (N) sub_warehouse
    │                         │
    │ 1                       │ 1
    ▼                         ▼
warehouse_layout (1)      shelf (N)
    │                         │
    │                         │ 1
    │                         ▼
    │                      location (N)
    │                         │
    │                         │ 1
    │                         ▼
    │                      inventory (N)
    │                         │
    │                         │ N
    └──────────────────────► goods (1)

warehouse_user (N) ────── (N) warehouse  （通过中间表 warehouse_user_relation 关联）
```

### 3.1 关键关联说明

- **warehouse ↔ warehouse_layout**：一个仓库可拥有多个历史平面图版本，但当前生效的只有一张，通过 `warehouse.layout_id` 指向当前平面图。
- **warehouse ↔ sub_warehouse**：一对多，子仓库在平面图上有明确坐标和尺寸，用于全景看板渲染。
- **sub_warehouse ↔ shelf**：一对多，货架必须归属到某个子仓库。
- **shelf ↔ location**：一对多，货架配置生成时，根据 `行数 × 排数 × 层数 × 列数`（row_count × bay_count × layer_count × col_count）批量生成货位。
- **location ↔ inventory**：一对多，一个货位可存放多个 SKU/批次；但同一货位 + 同一商品 + 同一批次通常只有一条库存记录。
- **warehouse_user ↔ warehouse**：多对多，一个库管可负责多个仓库，一个仓库可有多个库管。

## 4. 核心业务逻辑设计

### 4.1 平面图绘制与货架配置流程

1. 用户创建仓库，录入基础信息。
2. 进入平面图绘制页：
   - 在线绘制：保存墙体、分区等元素到 `warehouse_layout.layout_data`。
   - CAD/手绘导入：上传文件后由识别服务解析，生成 `layout_data` 和背景图。
3. 用户在平面图上框选货架区域，进入货架配置：
   - 输入货架模式（单排/双排）及行数、排数、层数、列数参数。
   - 系统根据参数批量生成 `shelf` 和 `location` 记录，并计算每个货位在平面图上的坐标。
4. 平面图或货架尺寸变更时，校验货位坐标是否越界，越界则提示调整。

### 4.2 全景可视化看板数据聚合

- 仓库级看板：
  - 总货位数 = COUNT(location.id)
  - 已占用货位数 = COUNT(location.status = 2)
  - 空间利用率 = 已占用货位数 / 总货位数 × 100%（或按面积加权计算）
  - 子仓库列表：按 sub_warehouse 聚合
- 子仓库级看板：
  - 货架列表、库存总量、各货架库存占比
  - 双击下钻到区域货架视图

### 4.3 智能找货流程

1. 用户输入货位编号 → 直接命中 `location.location_code`。
2. 用户输入商品名称/编码 → 联表查询 `goods` + `inventory` + `location`。
3. 返回结果包含：货位编号、所属货架、所属子仓库、商品信息、库存数量、平面坐标。
4. 前端根据坐标高亮定位，实现秒级找货。

## 6. 关键技术方案

- **平面图渲染**：前端使用 Canvas 或 SVG，支持拖拽、缩放、矩形区域框选。
- **CAD/手绘识别**：后端调用 OCR/图像识别服务，将图纸转换为平面图元数据；复杂 CAD 文件可借助开源库解析 DXF。
- **坐标体系**：以仓库平面图左上角为原点 (0,0)，所有子仓库、货架、货位坐标统一使用相对坐标，便于缩放和定位。
- **货位编码规则**：建议格式 `仓库编码-子仓编码-货架编码-层-行-排-列`，例如 `WH01-A01-S03-L02-R01-B03-C05`。
